# **USE CASE 6: View an Employee's Details**

## **CHARACTERISTIC INFORMATION** 

### **Goal in Context** 
_As an HR advisor I want to view an employee's details so that the employee's promotion request can be supported._

### **Scope**
Company.

### **Level**
Primary task.

### **Preconditions**
We know the employee's details. Database contains employee's details.

### **Success End Condition** 
HR advisor is able to view an employee's details.

### **Failed End Condition** 
No report is produced.

### **Primary Actor**
HR Advisor.

### **Trigger**
HR advisor wants to be able to view an employee's details.

## **MAIN SUCCESS SCENARIO** 
1. HR advisor requests for the ability to view an employee's details.
2. HR advisor is able to view an employee's details.
3. HR advisor can now support a promotion request. 

## **EXTENSIONS**
None.

## **SUB-VARIATIONS**
None.
