# **USE CASE 5: Add a New Employee's Details**

## **CHARACTERISTIC INFORMATION** 

### **Goal in Context** 
_As an HR advisor I want to add a new employee's details so that I can ensure the new employee is paid._ 

### **Scope**
Company.

### **Level**
Primary task.

### **Preconditions** 
We know the new employee so we can add their details. 

### **Success End Condition** 
Employee's details are added correctly.

### **Failed End Condition**
Employee's details have not been added. 

### **Primary Actor**
HR Advisor.

### **Trigger** 
HR advisor wants to be able to insert a new employee's details.  

## **MAIN SUCCESS SCENARIO** 
1. HR advisor gets new employee's details.
2. HR advisor inserts new employee's details.
3. The new employee's details are entered correctly.

## **EXTENSIONS** 
None.

## **SUB-VARIATIONS** 
None.

## **SCHEDULE**
**DUE DATE:** Release 1.0
