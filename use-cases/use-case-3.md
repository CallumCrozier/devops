# **USE CASE 3: Produce a Report on the Salary of Employees in my Department**

## **CHARACTERISTIC INFORMATION** 

### **Goal in Context**
_As a department manager I want to produce a report on the salary of employees in my department so that I can support financial reporting for my department._ 

### **Scope** 
Company.

### **Level**
Primary task.

### **Preconditions** 
We know the department. Database contains current employee salary data.

### **Success End Condition** 
A report is available for the department manager to provide to finance.

### **Failed End Condition** 
No report is produced.

### **Primary Actor** 
Department Manager.

### **Trigger** 
A request for finance information is sent to HR.

## **MAIN SUCCESS SCENARIO** 
1. Finance request salary information for the department.
2. Department manager captures name of their department to get salary information for.
3. Department manager extracts current salary information for all employees in the department.
4. Department manager provides report to finance. 

## **EXTENSIONS** 
None.

## **SUB-VARIATIONS**
None.
