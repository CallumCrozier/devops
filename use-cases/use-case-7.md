# **USE CASE 7: Update an Employee's Details**

## **CHARACTERISTIC INFORMATION** 

### **Goal in Context** 
_As an HR advisor I want to update an employee's details so that employee's details are kept up-to-date._ 

### **Scope** 
Company.

### **Level**
Primary task.

### **Preconditions**
HR advisor knows the employee's details.

### **Success End Condition** 
HR advisor is able to update an employee's details.

### **Failed End Condition** 
HR advisor is not able to update an employee's details.

### **Primary Actor**
HR Advisor.

### **Trigger**
HR advisor wants to be able to update an employee's details.

## **MAIN SUCCESS SCENARIO** 
1. HR advisor can access an employee's details.
2. HR advisor can update an employee's details.
3. HR advisor can keep employee details up-to-date.

## **EXTENSIONS**
None.

## **SCHEDULE**
**DUE DATE:** Release 1.0
